# 청년 화면

React + TypeScript + Vite로 만든 별도 프로젝트입니다.

```sh
npm install
npm run dev
```

터미널에 표시된 주소에서 시연 화면을 열 수 있습니다. 시연 데이터는 브라우저에 저장됩니다. 배포용 빌드는 `npm run build`로 확인합니다.

시연 모드에서도 고민에 링크나 전화번호를 입력하면 수정 안내가 표시됩니다. 위기 표현 안내는 백엔드의 대체 키워드 목록으로 시연합니다. 실제 연동 시에는 서버의 필터 오류 코드와 위기 감지 결과를 사용합니다.

팀 프로젝트에 합칠 때는 `src/YouthApp.tsx`, `src/model.ts`, `src/youth.css`를 함께 가져옵니다. 청년 진입 화면에서 CSS를 불러오고 `<YouthApp key={userId} userId={userId} />`로 렌더링합니다. `userId`에는 팀 프로젝트의 `getServerUserId()`가 반환하는 UUID를 전달합니다. API 서버 주소는 `.env.example`을 참고해 `VITE_API_BASE_URL`로 지정합니다.

고민 작성·수정·삭제, 공개 범위 변경, 내 고민 목록, 알림 목록·읽음, 답장 신고는 배포 Swagger의 경로를 사용합니다. 공개 피드, 고민 상세와 답장 표시, 좋아요, 고마움·후일담은 백엔드 `develop`의 계약을 사용합니다. 이 경로들은 배포 Swagger에 아직 나타나지 않아 배포 후 확인이 필요합니다.

공개 고민 신고와 후일담 공개 범위 변경은 확인한 백엔드 코드에 경로가 없어 시연에서만 동작합니다. 서버 알림을 누르면 읽음 처리 후 받은 답장 목록으로 이동합니다. 서버 모드의 사용자 흐름은 실제 계정으로 검증하지 않았습니다.
