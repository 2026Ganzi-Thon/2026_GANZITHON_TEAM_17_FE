# TEAM 17 프론트엔드

React + Vite. 제공된 ‘내 정보’ 제작 화면 목록에 따른 13개 화면 체험입니다. 디자인은 임시이며, 이름은 ‘서비스명’으로 표시합니다.

## 실행

```sh
npm install
npm run dev
```

표시되는 로컬 주소를 브라우저에서 엽니다. `npm run build`로 빌드합니다.

## 화면 범위

내 정보 기본 → 로그인/회원가입 기본 → SNS 계정 약관 → SNS 계정 약관 완료 → 이름/생년월일 → 이름/생년월일 완료 → 휴대폰번호 → 휴대폰번호 완료 → 주소 → 세부 주소 → 주소 완료 → 서비스 이용약관 → 서비스 이용약관 완료.

하단 ‘제작 화면 목록’을 펼치면 각 상태를 직접 열고 더미 정보를 채울 수 있습니다. 입력값은 메모리에만 유지되며 새로고침 시 초기화됩니다. 완료 화면은 서버 처리 완료가 아닌 입력 완료 상태입니다.

## 팀 공유용 더미 파일

`public/mocks/profile.json`을 공유하세요. 실행 중 `/mocks/profile.json`으로 조회합니다. 모든 값은 가상 예시입니다.

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| id | string | 예시 사용자 ID |
| name | string | 이름 |
| birthDate | string | YYYY-MM-DD |
| phone | string | 010-0000-0000 |
| address | string | 기본 주소 |
| addressDetail | string | 세부 주소 (선택) |
| socialConsent | boolean | SNS 약관 선택 여부 |
| serviceConsent | boolean | 서비스 약관 선택 여부 |

## 연동 전 범위

- SNS 제공자와 인증은 미확정입니다. 버튼은 화면 체험만 진행합니다.
- 휴대폰번호는 형식만 검사하며 SMS 인증을 수행하지 않습니다.
- 주소는 직접 입력합니다. 주소 검색 API는 연결 전입니다.
- 약관은 예시 표시이며 실제 약관 문안은 아닙니다. 동의 기록은 서버에 저장하지 않습니다.
- 백엔드 API/인증/회원가입/정보 저장은 미연결입니다.
- 온보딩, 홈, 시뮬레이션, 커뮤니티, 채팅은 아직 구현하지 않았습니다.

백엔드 명세 확정 후 사용자 조회/수정 API와 인증을 연결해야 합니다. 이 더미 스키마는 확정된 API 계약이 아닙니다.
