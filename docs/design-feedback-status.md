## 연결 시 유의 사항
- 손편지 OCR 검사는 답장 생성 POST 내부에서 실행된다. 별도의 검사 API가 없으므로 미리보기에서 검사 성공을 표시하지 않는다.
- OCR 자격증명 미설정/장애 시 서버는 검사를 건너뛸 수 있다. 성공한 답장 생성 응답만으로 OCR 통과를 보장하지 않는다.
- 사진 품질은 기기 내 임시 캔버스로 밝기와 명암 경계를 분석해 보조 안내한다. 경고가 있어도 사용자가 직접 확인하고 진행할 수 있다. 원본 업로드 파일은 변경하지 않고 OCR 결과로 표시하지 않는다.
- 사진 전송은 OCR 대기 시간을 고려해 45초 제한을 사용한다. 서버의 동일 고민 중복 답장 방지 정책을 유지한다.
- 어르신 답장 목록에는 본문이 없다. 현재 기기에 저장된 사용자별 전송 기록으로 본문을 표시한다. 다른 기기에서는 본문과 수정이 제한된다.
- 후일담은 답장 상세에서 사용자가 확인 버튼을 누르면 받은 마음 API로 조회한다. 이 API는 전체 목록을 읽음 처리하므로 버튼 아래에 이 동작을 안내하며 자동 호출하지 않는다. 선택한 replyId에 속한 항목만 표시한다.
- 신고 성공 시 서버가 즉시 고민을 숨긴다. 이후에 별도로 숨길지 선택하는 디자인은 API 정책 변경이 필요하다.
