# 어르신 원본 답장 재조회 적용 요청

현재 배포된 백엔드에는 청년 전용 `GET /api/replies/{replyId}`만 있습니다. 어르신 목록은 본문/이미지 주소를 제공하지 않으므로 기기 기록이 없으면 원본을 복원할 수 없습니다.

공식 백엔드 `develop`의 `65d3027`을 기준으로 [적용 패치](senior-reply-detail.patch)를 준비했습니다. 프론트 계정의 백엔드 push는 403으로 거부되어 서버 변경은 배포하지 못했습니다. 아래 적용은 백엔드 쓰기 권한이 있는 담당자가 진행해야 합니다.

## API

`GET /api/senior/replies/{replyId}`, `X-User-Id`: 작성한 어르신의 UUID

응답 data: `replyId`, `worryId`, `type`, `content`, `imageUrl`, `createdAt`

- 자신이 작성한 답장만 조회
- 삭제/숨김 답장 또는 삭제/숨김 고민의 답장은 차단
- 청년의 최초 조회 시각과 피드백 조건은 변경하지 않음
- 청년 개인정보나 고민 본문은 응답하지 않음
- DB 스키마 변경 없음

## 적용 및 확인

공식 백엔드 작업 브랜치에서 패치를 적용합니다.

```sh
git am /path/to/senior-reply-detail.patch
./gradlew build
```

JDK 21에서 실행해야 합니다. 소유자 원본 조회, 다른 어르신/청년 차단, 삭제/숨김 차단 및 최초 조회 시각 보존 등 통합 테스트 8개가 포함되어 있습니다. 현재 작업 환경은 JDK 17이라 이 Java 테스트는 실행하지 못했습니다.

검토 후 기존 `develop` → `main` 배포 절차로 반영합니다. 프론트는 새 API를 요청하고, 서버가 아직 `COMMON_404`를 반환하면 기기에 보관된 기록으로 대체합니다. 권한 거부 또는 삭제된 답장 오류에는 기기 기록으로 우회하지 않습니다.

## 실서버 확인

JPEG 업로드·원본 다운로드·청년 답장 상세 조회, 후일담 공개 범위 변경, 공개 고민 신고는 정상 응답을 확인했습니다. 어르신 전용 원본 조회는 현재 404이며 위 패치 배포가 필요합니다. 임시 고민과 답장은 검증 후 삭제했습니다.
